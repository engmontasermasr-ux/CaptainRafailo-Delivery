اختبار نشر تحديثات Captain Rafailo عبر GitHub Pages.
أنشئ مستودعًا عامًا باسم CaptainRafailo-Delivery.
ارفع الملفات مع الاحتفاظ بالمسارات: index.html و manifest.json و .nojekyll و content/update-test.txt.
فعّل Pages من Settings > Pages > Deploy from a branch > main / (root).
تأكد من فتح رابط manifest.json علنًا قبل إدخاله في Unity.
هذه تجربة تحديث ملف نصي فقط؛ لا تضيف لعبة أو تحدث APK.
لا تنشر أي مفاتيح توقيع أو بيانات خاصة.
